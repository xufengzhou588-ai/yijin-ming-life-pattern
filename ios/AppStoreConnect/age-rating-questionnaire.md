# Age Rating Questionnaire Draft

Status: draft answers for App Store Connect. Review the final app build before submitting.

## Expected Answers

- Cartoon or fantasy violence: `None`
- Realistic violence: `None`
- Prolonged graphic or sadistic realistic violence: `None`
- Profanity or crude humor: `None`
- Mature or suggestive themes: `None`
- Horror/fear themes: `None`
- Medical/treatment information: `None`
- Alcohol, tobacco, or drug use or references: `None`
- Simulated gambling: `None`
- Sexual content or nudity: `None`
- Contests: `No`
- Gambling: `No`
- Unrestricted web access: `No`

## Rationale for “No unrestricted web access”

The iOS app uses a controlled `WKWebView` to show the product's own hosted reading experience and legal/support pages. It is not a general-purpose browser and does not allow users to freely navigate the public web.

If future versions add arbitrary outbound browsing, update this answer.

## Safety Boundary

MING should remain a 4+ lifestyle/reference app only if final content continues to avoid:

- absolute fate claims;
- emergency, medical, legal, financial, or mental-health advice;
- frightening or coercive language;
- sexually explicit or violent content;
- user-generated public content.
