# Chibi Glass Daily Seals

Date: 2026-07-31

## Direction

Updated Daily Seals toward the selected visual direction:

- Main style: row 3 from the concept board, refined ancient miniature figures.
- Material reference: row 5 glass/spirit tile treatment.

## Why not GIF

The implementation stays with inline SVG and CSS animation instead of GIF. This keeps the icons crisp in iOS WebView, reduces app size, supports reduced-motion settings, and makes later adjustments faster.

## Changes

- Daily seal tiles are larger and more glass-like.
- Each seal now contains a more readable small ancient-style figure scene.
- Focus: seated practitioner with breathing compass aura.
- Spark: small figure raising brush/torch with animated flame.
- Ground: small figure stabilizing earth beside mountain strata.
- Connect: two figures with pulsing red-cord / knot symbol.
- Restore: spring, sprout, water motion, and caretaker figure.
