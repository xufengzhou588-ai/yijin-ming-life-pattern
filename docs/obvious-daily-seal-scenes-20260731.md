# v114 每日灵印明显版调整

时间：2026-07-31

本次调整目标：解决 v113 中 5 枚每日灵印“看起来还是原图标、人物不明显”的问题。

已完成：

- 版本号升级到 `v114`，避免浏览器继续显示旧缓存。

  - 安土：小人按住山土、山形与地脉层。

  - 养源：人物浇灌、泉水波纹、发芽植物。
- 保留 CSS 微动效：呼吸、火焰、按土、结绳、水波、发芽。
- 启动脚本默认打开地址改为 `/app?v=114`。
