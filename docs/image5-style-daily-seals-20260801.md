# v115 每日灵印改为图五方向

时间：2026-08-01

用户反馈：v114 的“小古风人物 + 玻璃按钮”是结合体，视觉效果一般，建议使用“图五”那种效果。

本次调整方向：

- 放弃复杂小人场景，改成统一的“玉牌 / 灵印 / 东方符号”体系。
- 每枚灵印以一个主符号为核心，辅以极简象形线条：
  - 定心：`心` + 罗盘定心环。
  - 起势：`势` + 火焰与上升光线。
  - 安土：`土` + 山形与地脉。
  - 结缘：`缘` + 同心结 / 红线结构。
  - 养源：`源` + 水波与发芽。
- 视觉重点从“说明性小插画”转为“可收藏的神秘东方灵印”。
- 版本号升级为 `v115`。
