# Daily Card Visual Refresh

Date: 2026-07-28

## Reason

The first Daily Focus card was useful but too report-like. It lacked the sense
of mystery and novelty expected from an Eastern-pattern product.

## Changes

- Reframed the daily stem-branch as a `daily mark`.
- Kept the Chinese seal glyph, such as `癸卯`, as the visual anchor.
- In English, date labels use pinyin-style transliteration such as
  `Gui-Mao Day` instead of forcing a literal translation.
- Replaced visible `Water → Wood` text with small 3D-style element orbs.
- Added a ritual strip with:
  - daily seal;
  - element flow icons;
  - short action-climate explanation.

## Product Boundary

The card still avoids fixed predictions. It presents the day as an action
climate and reflection prompt, not as an event forecast.

## Note

`癸卯` is the correct heavenly-stem/earthly-branch text. It should not be
written as `葵卯`.
