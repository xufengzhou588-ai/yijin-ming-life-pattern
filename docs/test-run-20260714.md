Observed:

- `https://developer.apple.com/programs/enroll/` is reachable from this network.
- Apple's direct start-enrollment link redirects to Apple ID login:
  `https://developer.apple.com/register/agree/?source=programs_enroll_start_enrollment&path=%2Fenroll%2F`
- Command-line access to Apple ID login returns 403 because it requires a real browser session and cookies; this does not mean the Apple page is down.

Recommended bypass:

1. Open the direct start-enrollment link in Safari.
2. If it does not jump, open a private Safari window and paste the link again.
3. Disable VPN/proxy/content blockers temporarily.
4. Make sure the Apple Account has two-factor authentication enabled.
5. Make sure the Apple Account first and last name are legal names, not alias/company-only text.
6. If web enrollment still fails, enroll through the official Apple Developer app from the App Store.

Official links:

- Program enrollment page: `https://developer.apple.com/programs/enroll/`
- Direct start-enrollment link: `https://developer.apple.com/register/agree/?source=programs_enroll_start_enrollment&path=%2Fenroll%2F`
