# Daily Boost Card

Date: 2026-07-29

## Purpose

Add a positive, fun daily encouragement inside the free Daily Focus card.

The goal is to help users start the day with a small sense of momentum while
avoiding unsupported claims about real user rankings.

## Behavior

The card highlights one friendly signal from the user's own chart structure:

- progress;
- resource;
- connection;
- stability.

It then displays a boost score between 72 and 94.

## Important Boundary

The score is **not** a real percentile against other users. The app has no
population dataset and should not claim real-world ranking.

User-facing copy says this is not a real user ranking. It is a light pattern
baseline prompt based on the user's own chart.

## Inputs

- career momentum score;
- wealth generation score;
- relationship support score;
- execution stability score;
- current daily theme;
- local date seed.

## Product Rationale

Most users enjoy a positive daily nudge. Even if the deeper reading is serious,
the daily card should feel like a small ritual that opens the day with good
energy.
