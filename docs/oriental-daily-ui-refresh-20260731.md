# Oriental Daily UI Refresh

Date: 2026-07-31

## Why

The previous Daily Boost score looked like a generic fitness/SaaS gauge, and the Daily Seal icons were too literal or abstract. This weakened the Chinese mystic identity of the product.

## Changes

- Daily Boost is now styled as a jade/bronze momentum seal instead of a circular gauge.
- The label changed from `指数 / score` to `启运 / seal`.
- Five Daily Seal icons were redesigned around clearer Eastern metaphors:
  - Focus / 定心: compass needle and centered target
  - Spark / 起势: rising flame and brush-like upward force
  - Ground / 安土: mountain, earth base, and strata
  - Connect / 结缘: knot / linked-heart structure
  - Restore / 养源: spring eye, water ripples, and sprout

## Product principle

Icons should be understandable without reading long text, but still feel like ritual marks rather than generic app symbols.
