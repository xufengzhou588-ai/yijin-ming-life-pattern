# Eastern Mystic Refresh

Date: 2026-07-28

## Direction

Move the product from a clean structured-report tool toward an Eastern symbolic
life-pattern system:

- symbols first;
- modern explanation second;
- no fear-based fortune telling.

## Changes

1. Hero / first impression
   - Added heavenly-stem and earthly-branch symbol band.
   - Added subtle ritual orbit and large `命` watermark.
   - Added richer gold/jade/dark-ink atmosphere.

2. Background system
   - Added global texture lines and radial ritual rings.
   - Added subtle Chinese watermark sigils per panel:
     - `四柱`;
     - `五行`;
     - `十神`;
     - `卦`.

3. Terminology
   - In English UI, core terms now remain as Chinese symbolic terms:
     - 五行: 木、火、土、金、水;
     - 十神: 比肩、劫财、食神、伤官、正财、偏财、正官、七杀、正印、偏印.
   - Modern explanation copy still uses plain language where needed.

4. Core archetype card
   - Reframed the right-side mark as a seal-like visual.
   - Strengthened gold-line, jade, and seal typography.

5. Daily Focus card
   - Added `今日签文` as a short ritual line.
   - Kept the modern action guidance below the symbolic layer.

## Product Principle

Do not over-translate core Chinese metaphysical terms. The app should let the
terms function as cultural symbols, then explain their practical meaning in
modern language.
